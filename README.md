🌿 Dincharya – AI-Powered Ayurvedic Wellness Platform

Dincharya is a full-stack personalized wellness platform inspired by Indian Knowledge Systems (IKS) and Ayurveda.
The application combines Ayurvedic Prakriti analysis, AI-powered diet recommendations, calorie tracking, and habit monitoring to help users improve their lifestyle in a data-driven and personalized way.
